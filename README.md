# 🎯 Python Quiz Game

A fun and interactive command-line quiz game built with Python.
This is my first Python project as part of my BCA Data Science journey.

---

## 📌 About the Project

This is a simple terminal-based quiz game where the player answers multiple choice questions.
It tracks the score and gives a result message at the end based on performance.

---

## ✨ Features

- Multiple choice questions (A / B / C / D)
- Personalized greeting with player name
- Score tracking after every question
- Final result message based on performance
- Easy to add your own questions

---

## 🖥️ How to Run

Make sure Python is installed on your computer.

**Step 1 — Clone or download this repository**
```
git clone https://github.com/yourusername/quiz-game-python.git
```

**Step 2 — Go into the project folder**
```
cd quiz-game-python
```

**Step 3 — Run the game**
```
python quiz_game.py
```
